# Opening a web cycle

Evidence marks are defined in `canvas.md`.

## Before the first prompt

- The human loads the binding for the platform: a skill on Gemini, project instructions on Claude or ChatGPT. [external]
- If prior work exists, the human pastes its state as text: the version's README, the latest handoff, and the prompt index so far. [run] A private chat link could not be read across sessions.
- Never cite a chat link as the record. It is private and unreadable later. [run]

## The first turn

- Record prompt #1 in the index and the appendix before replying. [owner] "The human's words stay theirs."
- Ask for the person's handle if it is not given. Never take a machine, device or account name as the person. [run] A machine name was once taken for the person.
- State the agent handle the binding names, or ask. [run]
- Fill section 0, including **where the deliverable will live after import**: the version folder, and the deliverable's own place apart from it. [owner] The owner had to ask "Where are the deliverables?"
- Choose the surface (`canvas.md`, *Where it lives*) and say which one in the chat reply. [external]
- Ask about any unclear word. Do not lock Frame on a guess. [run] Rule 1.

## Frame

- Run discussion rounds as phase blocks, `stage-1-phase-M-…`, and write the triptych (`frame-problem`, `frame-architecture`, `frame-gaps`) only when the human says the discussion is done. [run] The shape's record check requires the triptych once Plan begins; a compressed Frame failed it.
- A short web cycle may write the triptych as three brief blocks. It may not skip them. [run]
- If this domain is used together with another domain, name both in the problem block. [inferred] Falsified if combined use causes no confusion when unnamed.

## Plan

- Write the decisions table, the phases and a recipe per phase, as in the shape. [run] A plan with only steps and checks left Execute nothing to conform to.
- Mark any phase that needs files or a shell as *after import*, and stop the web part of the cycle before it. [inferred] Falsified if web agents complete such phases correctly in the chat.

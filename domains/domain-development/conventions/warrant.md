# Warrant: should this be a domain?

Evidence marks: `[owner]` the owner's words · `[run]` observed in recorded work · `[external]` an outside authority · `[inferred]` reasoned, with what would falsify it.

Ask these in order, and stop at the first yes.

1. **Does it recur?** If not, use a prompt. [run]
2. **Can the steps be stated exactly, with nothing to judge?** If so, write a program. [external]
3. **Do recorded departures already show a stage FPEV lacks, or a cadence a nested cycle cannot express?** If so, make an independent shape. A predicted need does not count: start as a domain. [owner]
4. **Otherwise it is a domain shape:** recurring know-how with judgment points, on FPEV's stages. [owner]

A **skill** is not a fifth answer. It binds one of the above to a harness, is derived from it, and is never its source. [inferred] Falsified if a skill holds lasting knowledge that its shape cannot.

## Signs of a real domain

- The same decisions and traps recur across at least two projects, or within one long project. [run]
- It keeps raising decisions that belong to a person. [run]
- It can be wrong in ways its mechanism cannot see. [run]
- Someone can name what a newcomer would otherwise re-derive. [run]

## Signs it is not one yet

- It has never been run through Verify. Run it first. [run]
- Only the agent believes it recurs. Ask the owner. [owner]
- It differs from an existing domain only in a few decisions. Borrow that domain and record what you struck; split only when the same strikes keep recurring. [run]

## When a domain should become its own shape

- Recorded departures show it needs a stage that FPEV does not have, with invariants of its own. [run]
- Recorded departures show a cadence that no nested cycle can express, such as a continuing journal with no project end. [run]

Moving a domain out is the owner's ruling. [owner]

## Output

Write the answer as a short warrant note in the development project: the case, the four answers with evidence, and what the owner decided. [inferred] Falsified if owners routinely skip the note with no later cost.

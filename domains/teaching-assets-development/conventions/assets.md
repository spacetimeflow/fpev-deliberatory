# Other course assets

Evidence marks are defined in `course-cycle.md`. These defaults rest on fewer runs than the lecture loop.

## Syllabus

- Start from the last offering's file and keep its exact format. Change only what must change. [owner]
- Do not add sections it lacked, such as outcomes or policies, unless asked. Mention a mandatory missing item in one line instead. [owner]
- Make accessibility fixes invisible: same look, correct structure. [run]
- Keep dates in one source, and check the syllabus, schedule and assignments against it. [run]
- Leave an unconfirmed policy as a visible marker for the instructor, and never invent it. [run]
- When a course fact changes, update every document that states it. A room change once left three documents disagreeing. [run]

## Announcements and handouts

- Draft for the instructor to post. [run]
- Use only links already verified on posted pages. [run]
- Follow the same accessibility rules as pages. [run]

## Homework, quizzes and exams

- Keep answer keys in an instructor folder that is never published, and publish only the student folder. [run]
- Run a pre-upload check that looks for keys, personal-server links, placeholder alt text and build artifacts. [run]
- Check extracted questions by count against the source. One extractor reported all answers while finding two questions. [run]
- Do not move a due date or relabel an assignment without flagging it for the instructor. [run]

## Student work

- Student submissions, names and grades are never copied into a course's public files, a handoff, or a domain. [inferred] Falsified if a recorded workflow needs them there and has no safer route.

# Presenting the theory

Evidence marks are defined in `frame-a-version.md`.

- The researcher sets the presentation arc. A common one is theory first, then tests. [owner]
- Use the abstract as the blueprint for a revision, and propagate each change through the whole article. [run]
- Fix terminology: one name per concept, chosen with the researcher. [run]
- Collect terms foreign to the field in a glossary, and define or replace them. [owner]
- Adopt a notation scheme and apply it everywhere, including the code. [run]
- No result is cited before it is stated. Check this mechanically. [run]
- Remove repetition. Simplify the main text by moving material to appendices, never deleting it. [run]
- Write wiki entries that let a capable student understand and verify the work. [owner]

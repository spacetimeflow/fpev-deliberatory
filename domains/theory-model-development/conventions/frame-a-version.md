# Framing a version

Evidence marks: `[owner]` the researcher's words or ruling · `[run]` observed in recorded work · `[external]` an outside authority · `[inferred]` reasoned, with what would falsify it.

- State the question the version answers, and what would count as success, in the researcher's words. [owner]
- List what is already established, what is preliminary, and what is only an idea. Preliminary results need rigorous verification. [owner]
- Name the deliverables: theorems, numerical checks, data tests, the article. [run]
- A major change, such as a new formulation or a new presentation arc, starts a new version. Keep the earlier one, with its challenges noted. [owner]
- Move superseded drafts into the predecessor folder and retire unused elements, recording the dispositions. [run]
- When related articles depend on this one, list them so changes can propagate. [run]
- Take a step back at each version: which application or question is most worth pursuing? [owner]

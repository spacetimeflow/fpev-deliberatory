# The record

Evidence marks are defined in `fetch.md`.

## The file

- Name it `YYYY-MM-DD_Channel_Short-Title`, a Markdown file, using the upload date, unless the folder has another convention. [run]
- Start from `templates/transcript.md`. [run]
- The header gives the title, channel, upload date, duration, language, the canonical address, description and chapters. [run]
- The header's **method line** says the route (manual track, automatic track by name, or model), the fetch date, the tool versions, the level of cleanup, the corrections list and the doubtful readings. [run]
- For automatic captions, say that they are unpunctuated or machine-punctuated, not speaker-labelled, and may contain recognition errors. [run]
- Record the fetch date, because automatic captions are revised. A re-fetch five weeks later differed in about 1 % of words. [run]

## Related files

- An analysis or summary is a separate file, named with `_analysis`, which links to the transcript. [owner]
- When the analysis was first drafted from a translated or automatic track, re-check its claims against the source-language transcript and say which were corrected. [run]
- Comments go in their own file, with the comment count and fetch date. [run]

## Verify

- Hand the owner one short list: the method line, each check flag and how it was resolved, the corrections, and the doubtful readings. [run]
- Do not report a transcript as finished while a flag is unresolved and unlisted. [run]
- Check an analysis written from the transcript against it before the owner reads either. [run]
- Record what the owner accepts or changes. [inferred] Falsified if owners never act on the list.

## Sharing

- Transcripts are copies of someone else's words, kept for the owner's research. Do not republish them, and say so in the header if the owner shares the folder. [inferred] Falsified if the owner's folder is public by design and the owner decides otherwise.
- Commenters' handles are personal data. Leave them out of anything shared. [inferred] Falsified if the owner's use requires attribution and the source allows it.

# Writing a piece

Evidence marks: `[owner]` the owner's words or ruling · `[run]` observed in recorded work · `[external]` an outside authority · `[inferred]` reasoned, with what would falsify it.

## Before writing

- Transcribe the owner's handwritten notes or images into markdown first, as the owner's input. [owner]
- Read the related pieces the owner names, and recent pieces for the format. [owner]
- Read the source itself. If only a summary or excerpt was available, say so. [run]

## The format

- Name the file `YYYY-MM-DD_kebab-case-title`, a markdown file in the explorations folder. [run]
- Front matter: status, created-at, authors with the agent's correct ID, prompted-by (the owner's prompts verbatim), relates-to, form, and an evidence note. [run]
- Open with "The answer in brief", then numbered sections, honest limits, and a short "For you to decide". [run]

## Voices and evidence

- Build on the owner's ideas. Do not substitute the agent's own framing for the owner's purpose. [owner]
- Mark who says what: the owner, the source or commenters, and the agent's readings, marked as unratified. [run]
- Link each outside claim. Say when it rests on search summaries rather than the work itself. [run]
- The evidence note lists what was read in full, in part, searched only, run, and not done. [run]

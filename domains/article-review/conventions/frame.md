# Frame: policy, the request, the reviewer's reading, the gaps

Evidence marks: `[owner]` the reviewer's words or ruling · `[run]` observed in recorded work · `[external]` an outside authority · `[inferred]` reasoned, with what would falsify it.

## First, the venue's policy

- Look up the publisher's current rule on AI in peer review, and record it with the date. Some publishers bar uploading a manuscript, or the report, into AI tools: Elsevier's journal policy does both, and its reviewer guidance also advises against AI help with the assessment itself (checked 2026-11-23). [external]
- The owner's practice is a model on the reviewer's own machine for anything that contains manuscript text. [owner]
- Hosted assistants may handle only what contains no manuscript text: published literature, the reviewer's own words when the reviewer allows it, and formatting. [run]
- Record in the Frame which model saw what. [inferred] Falsified if a venue's rules make the record unnecessary.
- If the venue forbids AI assistance outright, say so, and offer only tasks that do not touch the review. [external]

## Which request is this?

| Request | Deliverable | Default |
|---|---|---|
| First round | Full report | `understand.md`, `check.md`, `write.md` |
| Revision round | Verdict on each earlier comment | `revision.md` |
| Short format (extended abstract, conference) | One comment on core ideas: reasonable, novel, feasible | Brief; no technical audit |
| The reviewer's own comments | Their text, minimally edited | Record faithfully; check they are well founded only when asked |

- A short format leaves "no room for technical details". Comment on the core idea. [owner]
- When recording the reviewer's comments, make only minimal grammatical changes. [owner]

## The reviewer's reading

- Ask for the reviewer's first reading and questions, and any margin notes, in one exchange. [run]
- Treat the reviewer's handwritten or margin notes as their agenda, never as manuscript content. Transcribe them with the reviewer's intent marked as a reading to confirm. [run]
- Keep the reviewer's eventual verdict out of the agents' work until Verify, so that disagreement stays informative. [run]

## The reviewer's gaps

- Name what the reviewer must learn to verify the work, as well as the paper's research gaps. [owner]
- Use the reviewer's own background, for example their publication record, to decide what is a gap. [owner]
- Plan the wiki entries that will fill the gaps. [owner]
- Set the level the wiki aims at. The reviewer once asked for "college students". [owner]

## Tripwires

- The policy was not checked: stop. [external]
- Manuscript text is about to reach a tool not allowed for this review: stop. [run]
